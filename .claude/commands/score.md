---
description: Re-score ideas in the Idea Bank (fit score)
---

Read Engine Settings (Notion page), the Brand Voice & Style Guide (Notion page) and docs/brand/Aliyan_AI_Content_DNA.md first. Use the Notion MCP tools to read and write the databases, using the exact property names that exist there.

Input: $ARGUMENTS = idea titles, or empty for every row with Status = New.

1. Cluster: group ideas that are the same topic, even from different creators, and set Cluster + Topic tags.
2. Score each idea 1–10 on Brand fit, Audience fit, Phase fit, Pillar fit, Trend signal, Novelty (against the last 60 days of ideas and Scripts; near-duplicates ≤ 3), Originality, Scriptability (works in 25–35 s?).
3. Fit score = the weighted average using the DNA weights (Pillar fit not weighted).
4. Fit score ≥ the Settings auto-shortlist value → Shortlisted. Below 5 → Rejected with a one-line reason. Otherwise leave it New.

Then show the top 15 by Review rank: Idea · Pillar · Job · Fit · Trend · Review rank · one-line why.
