Read Engine Settings (Notion page), the Brand Voice & Style Guide (Notion page) and Aliyan_AI_Content_DNA.md first. Use the Notion MCP tools to read and write the databases, using the exact property names that exist there.

Research the idea in $ARGUMENTS. Use web search for anything current or time-sensitive.

Add a "## Research" section to the idea page:
- Verified facts, each with a source link
- Safe claims
- Risky claims: what to soften or drop
- Up to 5 talking points
- Examples: generic or verified only
- Label each point FACT, INTERPRETATION or MY POV
- Creator proof needed: if the angle needs my own result or story, write ⚠️ CREATOR INPUT REQUIRED: [exactly what]

Under 250 words. Don't change the idea's Status.
