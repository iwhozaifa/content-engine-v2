# Brand Voice & Style Guide

Version: 1.0 · Last updated: 2026-10-24

> Every script is written from this page. It takes over the "Language and script style" section of Content DNA. **First-time setup:** compare it with section 8 of your Aliyan_AI_Content_DNA.md, keep whichever wording is newer, and then delete section 8 from the DNA, so the rules live in one place.

## 1. Voice in one line

Direct, confident, a bit contrarian. Big-brother energy: I've done this, here's the shortcut. No hype.

## 2. Language

- **Mix:** 70% English / 30% Roman Urdu. Urdu carries emotion, punch and relatability ("yaar", "seedhi baat", "bas itna samjho"). English carries the concepts.
- **Always English:** AI, tool names, business and money terms (client, offer, workflow, freelancing, income, system).
- **Code-switch naturally,** mid-sentence where a person would. Never translate the same line twice.
- **Reading level:** a smart 20-year-old who knows ChatGPT but not workflows.

## 3. Rhythm and structure

- Lines of 4–12 words. One idea per line.
- Use contrast ("Skill se kaam milta hai. System se paisa."), parallel phrasing, short questions, short metaphors.
- Rhyme only when it happens naturally. Never force it.
- The first 3 seconds name a pain, a contradiction or a promise. Never "Hey guys" or "In this video".
- End on a line someone would quote or screenshot, then one CTA.

## 4. Vocabulary

| Use | Avoid |
| --- | --- |
| system, leverage, skill, client, offer, proof, rupees/dollars | game-changer, unlock, dive in, revolutionary, insane |
| "seedhi baat", "yaar", "samjho", "bas" | "in today's fast-paced world", "let's explore" |
| specific numbers you can back up | made-up stats, "everyone is making $10k" |
| "I tried", "I tested" (only when true) | invented personal stories |

## 5. Dos and don'ts

**Do**
- Take a clear side.
- Give one usable takeaway per video.
- Show the "how" in at least one beat.
- Say "CREATOR INPUT REQUIRED" when a line needs your real proof.

**Don't**
- Become an AI tool directory, generic motivation, get-rich-quick, freelancing-only or a random opinion page.
- Copy another creator's wording, examples or stories.
- Stack 3 CTAs. One action only.
- Explain what the viewer already understood.

## 6. CTA conventions

- Pull the wording from the **CTA Bank**, matched to the content job: Reach → Follow or Share, Trust → Save or Comment, Conversion → DM START or DM AUTOMATE.
- Maximum 1 Conversion CTA a week (current growth phase).
- The CTA is the second-to-last line, or the last line if there's no loop ending.

## 7. Hooks

Use the **Hook Library** families (Contrarian, Pain, Curiosity, Challenge, Rhythmic). The 3 hook alternates in each script must come from 3 different families.
